# Regional Sales ML Studio

Streamlit app: Data Analysis, Visualization, Predictive Analysis, Forecasting.

## Run
```
pip install -r requirements.txt
streamlit run app.py
```
The dataset `Denormalize_regional_sales_data.xlsx` is loaded automatically from this folder
(first load takes ~30 s, then it is cached). You can also upload another file from the sidebar.
